# EV Market Performance & Insights

A comprehensive data analytics and web visualization project analyzing Electric Vehicle (EV) market trends, manufacturing performance, battery capacities, and pricing insights.

## 🚀 Live Demo & Dashboard Links
* **Live Web App (Render):** [https://ev-market-performance-3.onrender.com/](https://ev-market-performance-3.onrender.com/)
* **Interactive Tableau Public Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/manika.gupta/vizzes)

## 📌 Project Features
* **Flask Web Integration:** Python Flask application embedding interactive Tableau dashboards.
* **Tableau Analytics:** Story points exploring sales growth, battery technology, and market segment pricing.
* **Data Sources:** Cleaned EV market datasets covering specs and market metrics.

## 📁 Repository Structure
* `app.py` - Core Flask application file.
* `templates/` - HTML layout files for dashboard embedding.
* `static/` - CSS stylesheets.

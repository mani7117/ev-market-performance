# ⚡ EV Market Performance & Insights

An interactive data analytics project that explores Electric Vehicle (EV) market trends, battery technologies, manufacturer performance, pricing, driving range, and customer ratings through **Tableau dashboards and a Flask-based web application**.

## 📌 Project Overview

The electric vehicle industry is evolving rapidly, making it important to understand market trends and performance indicators.

This project analyzes an EV dataset to explore patterns across manufacturers, battery technologies, vehicle specifications, pricing, and customer ratings.

The analysis is presented through interactive Tableau visualizations and a web application that brings the dashboard and data story together in one place.

## 🎯 Project Objectives

* Analyze EV market trends and manufacturer performance.
* Explore battery technology distribution and vehicle specifications.
* Compare pricing, driving range, and customer ratings.
* Identify patterns and relationships among key EV metrics.
* Present findings through interactive and accessible visualizations.

## 📊 Dataset Overview

The project uses an EV dataset containing information about:

* Vehicle manufacturers and models
* Model years
* Battery technologies and capacities
* Driving range
* Vehicle pricing
* Customer ratings
* Sales-related metrics

*Note: The dataset is used for project-level analysis and should not be interpreted as a complete representation of the global EV market.*

## ⚙️ Run Locally

Follow these steps to run the web application on your system.

**1. Clone the repository**

```bash
git clone https://github.com/mani7117/ev-market-performance.git
```

**2. Navigate to the project folder**

```bash
cd ev-market-performance
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install Flask**

```bash
pip install flask
```

**6. Run the application**

```bash
python app.py
```

**7. Open in your browser**

```text
http://127.0.0.1:5000
```
